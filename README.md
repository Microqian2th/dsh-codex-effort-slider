# dsh-codex-effort-slider — 性能与交互改进分支

用于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的推理等级滑条，基于 [Microqian2th/dsh-codex-effort-slider](https://github.com/Microqian2th/dsh-codex-effort-slider) 的已发布 **1.1.4** 改进。

> 这是 [Yutai233 的改进分支](https://github.com/Yutai233/dsh-codex-effort-slider/tree/perf/slider-preview-animation)，不代表上游已合并或发布。初次整合基线为 `fc5a994`。保留原作者、MIT 许可证和插件包标识；npm 同名包仍指向上游发行版，不能用它判断是否装到了本分支。

## 使用行为

- **拖动**：滑条和菜单右上角档位文字实时预览，松手后才提交最终档位。
- **单击**：点击轨道对应位置，松手确认，旋钮连续移动到目标档位。
- **键盘**：方向键调整，Home/End 到两端。
- **切换模型**：新模型明确支持原思考强度 ID 时保留该档位，不支持时使用宿主原默认逻辑。
- **打开模型菜单**：按钮临时显示“请选择模型或思考强度”，原文字与提示整句交叉淡化，不逐字露出；关闭后恢复当前模型与档位。
- **菜单动效**：缩小模糊的面板淡入展开；切换子面板和关闭也有对应过渡，悬停不会取消入场动画。
- **紫边**：Medium ↔ High 等能量边界以约 180ms 淡入淡出，不突然开关。
- **设置**：右键或长按滑条打开动画和刻度设置。
- **错误处理**：提交失败回滚；关闭或卸载时恢复真实文字及原有样式。

## 改进内容

### 滑条性能

1. **预览与提交分离**：去掉拖动跨档写回，保留松手/键盘提交、同档去重和错误处理。
2. **高频更新脱离 React state**：rAF 通过 ref 同步位置、标签、ARIA、title 和刻度，拖动起手/跨档不触发组件重渲染。
3. **减少布局读写**：旋钮使用 `translate3d`，全宽填充层以 `clip-path` 控制终点；按需缓存轨道几何，并在节点、窗口、滚动和尺寸变化时刷新。
4. **稳定粒子**：固定 22 个粒子节点及 duration/delay，使用可见性和暂停状态控制密度，避免不断重设相位。
5. **减少重绘**：静态位置渐变、独立光晕层和描边层，只调整必要的透明度，不逐帧重建背景和不同强度的阴影。
6. **改善单击起步**：首帧按 1/60 秒推进，后续根据实际帧间隔以不大于 1/120 秒的子步积分。

### 菜单与文字

- 主菜单约 280ms 从 86% 尺寸、6px 模糊和透明展开到清晰；子面板约 200ms 轻量过渡。
- 关闭约 180ms 反向缩小、模糊淡出；使用不可交互的短暂快照，不延迟宿主关闭、焦点恢复或实际模型选择。
- 模型文字与提示文字双向交叉淡化。文字区域从首帧使用最终自然宽度，不做横向宽度补间，避免末尾字符逐个出现。
- 仅实际按下或键盘操作可结束缩放；悬停和鼠标移动不会取消动画。
- 可见性恢复后补播入场，不因宿主隐藏测量时间较长而永久跳过。首次接入在绘制前准备，后续扫描仍按需合并。
- 菜单缩放期间按布局/视觉尺寸比例换算滑条坐标，动画结束后重测。
- 菜单动效遵循“减少动态效果”：使用不超过 100ms 的纯透明度过渡，省略缩放和模糊。

详见 [菜单展示说明](docs/MENU_PRESENTATION.md)。

### 切换模型保留档位

在会话目录上安装可恢复、引用计数的 `select` 适配器，在**原来的那次模型请求**中携带兼容档位；不通过额外请求事后补救。

- 使用调用时已生效的档位 ID，或旧模型明确的默认 ID，不使用拖动草稿、乐观显示或显示名。
- 旧、新模型目录均须明确支持该 ID；未知目录和无推理模型不强行携带。
- 同模型的档位操作不拦截；明确指定非默认新档位的请求保持原样。
- 模型身份变化会清理旧预览、旧动画和未发送档位，防止旧操作污染新模型。

**取舍：**宿主有些模型选择路径会自动带入目标默认值，无法与第三方明确要求目标默认值区分。因此，跨模型请求省略档位或等于目标默认值时，会优先保留兼容旧档位。详见 [切模规则与生命周期](docs/MODEL_SWITCH.md)。

### 其他有意改变的观感

- 跨档改为松手确认，不再立即写回宿主。
- 粒子速度固定为原 High 档基准，简洁模式仍放缓；密度随位置变化。
- 渐变固定在轨道位置，不再逐帧拉伸到填充终点。

这些不只是零行为变化的内部重构。

## 测试

需要 **Node.js 22 或更高版本**。没有额外 npm 依赖，不需要先安装 React 或 DSH。

```sh
npm test
# 或
node test/run-tests.mjs
```

单独运行：

```sh
npm run test:functional
npm run test:performance
npm run test:lifecycle
npm run test:menu
npm run test:model-switch
npm run test:border
```

- **功能测试**：689 项离线断言；未提供真实宿主产物时，明确跳过可选宿主源码契约检查。
- **专项测试**：性能行为、菜单生命周期、悬停与延迟可见性、整句文字过渡、切模保留与旧草稿隔离、紫边过渡及卸载清理。
- **CI**：Node.js 22/24 × Ubuntu/Windows；以 [Actions](https://github.com/Yutai233/dsh-codex-effort-slider/actions) 的具体提交结果为准。
- **浏览器回归**：打开 [独立浏览器测试页](test/browser/menu-presentation.html?verify-regression=1)，等待结果输出。页面加载本分支实际控制器，不接真实会话；检查原生 WAAPI 中间帧、悬停不取消、隐藏后恢复、整句宽度稳定和末字容纳。

如需额外检查真实宿主产物，设置 `DSH_MODEL_SELECTION_BUNDLE` 后运行功能测试；未提供则跳过，路径无效则失败。不要把宿主归档或配置提交到仓库。

**验证边界：**Node 测试使用假 DOM/React/宿主；独立浏览器页使用构造外壳。它们不是对所有 DSH 版本的端到端保证，也不是 FPS、GPU 或耗时基准。真实浏览器验收见 [测试说明](docs/TESTING.md)。

## 安装本分支

修复在 `perf/slider-preview-animation`，尚未合入本 Fork 的 `main`。

推荐 [下载分支 ZIP](https://github.com/Yutai233/dsh-codex-effort-slider/archive/refs/heads/perf/slider-preview-animation.zip)，解压到固定位置，在 DSH **设置 → 插件 → 添加插件** 中使用包含根目录 `package.json` 的本地目录。

支持 GitHub 分支来源的插件面板也可使用：

```text
github:Yutai233/dsh-codex-effort-slider#perf/slider-preview-animation
```

不要省略分支名，也不要同时启用上游版和改进版。已安装上游版时先通过插件面板切换来源并备份配置。不同 DSH 版本界面可能不同；修改后完全退出并重开 DSH，只刷新页面未必重新读取宿主缓存。

原项目安装脚本没有在本次重写或重新验证；不要为测试直接改写真实 profile。
