# 测试与验证边界

## 运行

要求Node.js >=22。无需安装依赖、启动DSH、登录GitHub或提供API key。

```sh
node test/run-tests.mjs
```

完整入口依次运行：
1. `client.test.mjs`：离线功能断言，覆盖读写、交互、运动、文字回滚和卸载。
2. `performance.test.mjs`：单版本行为预算测试，零备份/本机目录依赖。
3. `lifecycle.test.mjs`：观察器和菜单复用/滚动专项。

当前功能套件本地验收为689项通过。专项测试采用Node assert，失败会返回非零退出码。不要把689理解为真实浏览器端到端测试数。

## 可选真实宿主源码检查

功能测试的第12节仅在设置`DSH_MODEL_SELECTION_BUNDLE`时检查真实宿主脚本。未设置会明确打印SKIP；无效路径会失败。该检查依赖特定产物形状，不等于运行时兼容性保证。标准CI不包含宿主归档，因此会跳过这一项。

## 性能行为预算

- 假轨道宽200px、旋钮直径28px，60次move后：0次React渲染、1次几何读取、0次宿主提交；松手后1次最终提交。
- 记录粒子duration/delay，拖动中保持不变。
- High→Max单击：首帧有非零且非瞬移的位移，混合帧间隔下单调到位。
- 待宿主微任务落定后，动画段无额外React渲染或渐变/背景尺寸写入，行阴影不反复改变。

这些数字来自假React/假DOM，并非耗时、GPU开销、FPS或所有模型下的普遍上限。测试只覆盖所构造场景。

## 真实浏览器手动验收（提交者填写）

- [ ] 系统、浏览器/Electron、DSH版本、插件来源和分支已记录。
- [ ] 拖动文字预览、松手实际提交、失败回滚正确。
- [ ] 连续单击相邻/远端档位，没有启动停顿、反向跳动或错误落点。
- [ ] 键盘、不同档位数量、菜单往返、窗口尺寸变化、滚动、设置、深浅主题正常。
- [ ] 没有同时启用两个同名插件。
- [ ] 如报告性能提升，附Performance录制方法及真实帧时数据；否则仅报告离线计数。
