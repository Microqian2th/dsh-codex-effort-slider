# 建议标题

perf: decouple slider previews from host commits and optimize click animation

# 以下正文可复制到Pull Request

## 背景

拖动时连续更新React/布局及粒子计时会叠加开销；单击起步时首个rAF的dt可能接近1ms。原跨档写回还会触发宿主更新，而菜单文字未跟随本地预览。

本修改基于已发布1.1.4整理。整合时已核对上游与Fork默认分支均为 `fc5a994e34d3329bef748135e2c2ed219b9e30ce`，客户端基线与原始1.1.4一致；后续提交前若上游有更新，应重新检查差异。

## 修改

- 拖动只预览，松手提交最终档位；保留键盘、去重、在途合并和错误处理。
- ref+rAF更新视觉、文字、刻度和ARIA，不因起手/跨档setState。
- transform旋钮、全宽层clip-path、节点身份绑定的轨道几何缓存。
- 固定22粒子节点及计时；密度通过可见性控制，隐藏动画暂停。
- 静态位置渐变、独立阴影层opacity、按需边框/文字更新。
- 首帧1/60秒，之后不大于1/120秒子步积分。
- DOM观察器过滤及帧合并；修复复用菜单容器、滚动补画、文字恢复等生命周期场景。
- 菜单缩放模糊淡入和反向淡出，提示与真实模型文字整句交叉淡化，不做宽度揭字；悬停不会取消入场，延迟显示可恢复。
- 切换模型时在原请求内保留兼容已生效档位，目录适配器引用计数恢复；隔离旧模型的预览/乐观态。
- 独立紫边层180ms透明度双向过渡，保留宿主原阴影和布局。
- 扩展功能测试及菜单、切模、紫边专项，提供相对路径原生浏览器回归页，保留Node22/24 × Windows/Ubuntu CI。

## 有意改变的行为

- 跨档不即时写回，改为松手确认；菜单显示预览，收起态显示已生效档位。
- 粒子速度固定在原High基准，简洁模式继续放缓。
- 渐变固定轨道位置；紫边只切换独立层目标透明度，以CSS做淡入淡出。
- 跨模型请求省略档位或等于目标默认档位时，优先继承旧模型的兼容档位；明确非默认值及同模型Default操作不覆盖。
- 打开模型菜单时按钮显示“请选择模型或思考强度”，关闭后恢复真实文字；系统减少动态时仅保留短透明度过渡。

请维护者评估上述取舍；它不只是零行为变化的性能重构。

## 测试

本地整理版本的689项功能断言及新增专项均通过；真实宿主源码契约项默认显式跳过。`npm test`可复现离线套件，无需安装运行依赖。

60次move场景检查0次React渲染、1次几何读取、0次拖动写回，松手最终提交1次。单击场景检查首帧位移、到位、静态背景和无额外动画段渲染。

以上是离线假宿主计数，不是浏览器FPS。CI远端结果请以Actions为准。
