# 切换模型保留兼容思考强度

## 原因和修复位置

宿主的鼠标模型选择省略reasoningEffort，键盘等路径可能自动携带目标模型defaultEffort；切换后因此落到新模型默认/Default。

本修复不修改DSH本体文件。在插件使用的会话目录实例上安装可恢复、引用计数的select适配器，在原请求发送前补齐兼容档位。原请求只调用一次，不监听store变化后补发“修复”请求。

## 保留规则

- 必须切换了提供方或模型ID；同模型设置强度（包括主动选Default）不拦截。
- 原档位取调用当刻目录快照中的已生效ID，或者旧模型明确的默认ID；不使用拖动草稿、乐观值、显示名称或全局缓存。
- 新模型的efforts必须明确包含相同ID，旧ID在旧模型目录也必须有效。
- 新请求省略档位，或带目标模型自动默认档位时保留旧ID。
- 请求明确带非默认新档位时尊重新值；显式null/空串等也原样交宿主处理。
- 不支持/无推理档位/目录未知时不强塞旧档位，使用宿主原选择逻辑。

注意：宿主没有标记“这是自动带入的默认值”还是“第三方调用者明确要求目标默认值”。本适配器在跨模型时将等于目标defaultEffort的值视为自动默认；这是为了兼容宿主键盘等路径而做的有意取舍。

## 生命周期和显示

- 一个目录只包装一层，多使用者引用计数，卸载时还原原始属性/原型形态，不覆盖之后的外部替换。
- 保留原select的this、额外参数、同步异常及返回值/Promise身份。
- 目录实例换代时重解析并转移适配器；冻结/只读目录或快照读取异常时不阻塞原选择。
- 模型身份变化时清理旧动画、草稿和未发送档位，乐观显示绑定模型身份，避免旧拖动或旧模型显示污染新模型。

## 验证

新 `test/model-switch.test.mjs` 使用能真正写入完整provider/model/effort的假目录，不依赖旧测试桩只更新effort的简化行为。覆盖兼容/不兼容、跨提供方、目标默认、明确档位、一次请求、失败、原始方法身份、引用计数、实例迁移、卸载恢复及旧草稿隔离。

真实DSH界面需要在安装或更新后完全退出重开再实际检查。该适配器经离线模型切换专项验证，不代表已经验证所有DSH版本。
