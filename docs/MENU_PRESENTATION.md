# 模型菜单提示、弹出与返回动效

本分支在插件内增强宿主菜单展示，不修改 DSH 本体，不接管模型选择或焦点状态。

## 交互

- 点开模型按钮后，原模型名和档位文字在视觉上隐藏，显示“请选择模型或思考强度”。
- 原文字节点、图标、点击处理、ARIA、当前选择和键盘焦点仍由宿主管理；关闭后直接恢复原节点，因此不会恢复成过期的模型名。
- 主菜单：约280ms，从86%尺寸、6px模糊、透明逐渐展开到原尺寸且清晰。
- 模型/思考强度子面板：约200ms的较轻缩放与淡入。
- 模型名与提示文字之间双向交叉淡化，旧文字以不可交互的短暂副本淡出，新文字整句淡入。文字区域从首帧使用最终自然宽度，不做横向宽度补间，避免后几个字逐个露出；保留宿主原节点。
- 关闭/选中模型后：约180ms不可交互、aria-hidden/inert快照反向缩小到86%、模糊淡出；按钮最新模型/档位文字以180ms淡入恢复。不阻塞宿主关闭、选择确认或焦点恢复，快照有清理兜底。
- 悬停、指针进入、pointermove均不取消动画。只有真实按下和键盘操作才可立即结束缩放，避免影响滑条落点。
- 尊重系统“减少动态效果”，保留100ms以内的纯透明度过渡而省去缩放/模糊；运行中更改偏好会取消旧动画。
- Medium ↔ High的紫边改为独立描边层，通过180ms透明度过渡双向淡入淡出，不逐帧修改宿主行阴影；极小浮点残差不触发边框。

## 稳健性

支持菜单初始隐藏测量期、role=group的模型面板、无推理档位、快速开关、同节点面板切换、插件卸载、滚动/窗口/内容尺寸改变；WAAPI缺失时降级为正常显示。

菜单缩放期间，滑条使用布局宽度与视觉宽度比例换算；结束动画后重新测量。菜单动效不加入滑条的逐帧React更新或宿主写回。

## 验证

- 运行 `node test/run-tests.mjs`，包括原689项功能断言、性能行为、生命周期和新增菜单展示专项。
- 使用已安装Edge的原生浏览器引擎，在独立本地演示中验证提示隐藏、WAAPI、模型面板、退出快照及清理；不是对当前真实DSH页面的自动验收，也不是FPS测量。
- 独立预览使用实际 `createMenuPresentation` 控制器，外壳为演示构造，不读取真实会话。

真实DSH仍需完全退出重开后检查：按钮文案、菜单开关、模型/思考强度面板、快速点击、拖动落点、键盘和窄窗口显示。
